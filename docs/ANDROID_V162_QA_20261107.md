# RE:VE Android v1.6.2 — QA and deployment checklist

Source: Google Drive `REVE_SITE_v1_6_20261106/REVE_Android_v1.6.2_Source_20261107.zip`.

- Reuses the archived Android v1.6.1 WebView code and its icon resources.
- Updated Android version: `versionCode=162`, `versionName=1.6.2`, package `site.lexid.reve`.
- Native Home, Products, Sound Lab, Journal tabs preserve `reve.language` (ko/en/zh-CN/ja) across navigation; Korean is default.
- Added reload, share, load progress, main-frame network/SSL error retry; restricted in-WebView navigation to HTTPS `reve.lexid.site`.
- Honors external HTTPS, mailto and tel in system apps, and routes trusted downloads to DownloadManager.
- Debug APK is generated with disposable debug signing; it is **not** a Play Store release or proof of physical device QA.
- Tests: zip integrity, Gradle compile, lint, APK nontrivial size, APK ZIP integrity, Android APK signature.
- Before production: Android physical-device and emulator QA, screen readers, keyboard and font scaling, OAuth handoff, icon/splash visual check, Play Store keystore, privacy and data-safety forms, signing and target SDK audit.
- The legacy `downloads/REVE_Android_v1.6_debug.apk` is 1,506 bytes, not a verified distributable. Do not overwrite it before a verified replacement exists.
- Do not claim Sonic OS controls physical speaker hardware; current website is a concept demo.
